FONT PARFUMERIE SCRIPT PRO
==========================
File ParfumerieScriptPro.woff2 trong thư mục này là bản đã cắt gọn (chỉ chữ Latin + tiếng Việt, ~300KB) từ file .ttf gốc bạn tải về.
Website dùng nó cho: tên cô dâu chú rể, logo N/L, tiêu đề các mục (Faq's, You're Invited, The Details...).

Chỉnh độ lớn / độ đậm chữ thư pháp: trong site/assets/css/base.css, mục .t-script
  --script-scale: 1.25   (1 = nguyên cỡ thiết kế, tăng để chữ to hơn)
  --script-stroke: .5px  (0 = không làm đậm nét)

Nếu muốn dùng file gốc: đặt ParfumerieScriptPro.ttf hoặc .otf vào đây (web tự dùng khi không có .woff2).
Lưu ý giấy phép: kiểm tra font có cho dùng trên website (webfont license) không, vì file font nằm công khai trên GitHub Pages.
