# Ảnh

Hiện tại mọi ảnh được lấy trực tiếp từ trang mẫu gốc (không lưu bản sao trong dự án).

## Cách thay bằng ảnh của bạn
1. Chép ảnh vào `site/assets/img/own/`.
2. Mở `site/assets/js/config.js`, thêm vào `imgOverride` một dòng:
   `"<tên-file-gốc>": "assets/img/own/<ảnh-của-bạn>"`.
